# Player avatars

The four profile pictures a player can choose from during profile setup.

The current `avatar-01.svg` … `avatar-04.svg` files are placeholders. To replace them, add the new
images here and update `src/data/player-avatars.json` (file name and label). Keep exactly four
entries unless the team decides otherwise — the setup screen lays them out in a 2×2 grid.
